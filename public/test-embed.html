SZLG Donation Banner - Test Page

This is a test page demonstrating the Szent László Gimnázium donation banner.

How to Use

To add this banner to any website, simply include the following script tag in your HTML <head> section:

<script src="https://adomany.szlg.info/script.js"></script>

Features

  • Auto-dismiss with localStorage: Once dismissed, the banner won't show again on that browser
  • Responsive design: Adapts to mobile and desktop screens
  • Smooth animations: Slides down on load, fades out on dismiss
  • Click-through: Clicking the banner (except the dismiss button) opens adomany.szlg.info
  • Shows tax number: 18014125-1-42
  • No dependencies: Pure vanilla JavaScript
Note: To test the banner again after dismissing it, clear your browser's localStorage for this domain or open in an incognito/private window.
